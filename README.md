# Evently — версия для GitHub Pages

Это статическая демонстрационная версия сайта на HTML, CSS и JavaScript. Она не требует Python и может публиковаться через GitHub Pages.

## Публикация

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в корень репозитория содержимое этой папки: `index.html`, `app.js`, `style.css` и папку `static`.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
5. После публикации GitHub покажет ссылку в разделе Pages. Она будет вида `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Ограничения демонстрационной версии

- Страницы, карточки событий и визуальная форма регистрации работают в браузере.
- Форма регистрации только проверяет заполнение и показывает демонстрационное сообщение. Она не отправляет и не сохраняет персональные данные.
- Добавление событий в разделе «Администратор» сохраняет их только в локальном хранилище текущего браузера. Эти изменения не видны другим посетителям.
- Для общей админ-панели, настоящей регистрации и единой базы участников нужен сервер и база данных. Не публикуйте персональные данные в репозитории GitHub.

## Локальный просмотр

Откройте `index.html` в браузере. Для проверки сайта не нужны Python и виртуальное окружение.
