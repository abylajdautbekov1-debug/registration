КАК ОПУБЛИКОВАТЬ САЙТ ЧЕРЕЗ GITHUB PAGES

1. Создайте на GitHub новый репозиторий и выберите Public.
2. Откройте репозиторий → Add file → Upload files.
3. Загрузите содержимое этой папки: index.html, app.js, style.css и папку static. Сам ZIP загружать не нужно — сначала распакуйте его.
4. Нажмите Commit changes.
5. Откройте Settings → Pages.
6. В разделе Build and deployment выберите Deploy from a branch.
7. Выберите ветку main и папку /(root), нажмите Save.
8. Подождите завершения публикации и откройте ссылку, показанную в разделе Pages. Обычно она выглядит так:
   https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/

САЙТ В БРАУЗЕРЕ

Главная страница, карточки мероприятий и переходы между страницами работают как статический сайт.
Форма регистрации здесь демонстрационная: она не отправляет и не сохраняет данные участников.
Добавленные в админ-разделе мероприятия хранятся только в браузере того компьютера, где их добавили.
Для настоящего сайта с общими событиями и регистрациями нужен сервер с базой данных.

Для публикации отправляйте заказчику ссылку GitHub Pages. Ссылку на репозиторий используйте для передачи кода.
